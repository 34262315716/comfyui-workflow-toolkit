# 离线渲染：把工作流画成图

## 一句话

`cwf render 某流 --out preview.svg` —— **不开浏览器、不开 ComfyUI 前端、不联网**，
直接把工作流 JSON 画成图。

---

## 为什么默认出 SVG

cwf 承诺**零第三方依赖**（换台 ComfyUI 机器拷过去就能跑），所以默认产物是 SVG：

| | SVG | PNG |
|---|---|---|
| 依赖 | **纯标准库** | 需要 Pillow（ComfyUI 的 venv 必然有） |
| 体积 | 一张 3000×800 的图约 300 KB 文本 | 同尺寸约 100–300 KB |
| 缩放 | **矢量，放多大都不糊** | 位图，缩过头字就糊 |
| 用途 | 大图、存档、贴进文档、diff | 直接看、发给别人、贴聊天窗 |

两种产物**共用同一套几何与布局代码**（只在最后的绘制原语上分叉），
所以形状、位置、颜色完全一致，不会出现"导出的图跟预览不一样"。

机器上没 Pillow 时 `--out x.png` 会明确告诉你两条出路（改用 SVG，或 `pip install pillow`），
不会甩一堆 traceback。

---

## 命令

```bash
cwf render 某流 --out preview.svg              # 矢量（推荐）
cwf render 某流 --out preview.png              # 位图
cwf render 某流 --out p.png --scale 2          # 整体放大 2 倍
cwf render 某流 --out p.png --max-px 8000      # 长边上限（PNG 默认 4200，SVG 默认不限）
cwf render 某流 --out p.png --theme light      # 亮色主题
cwf render 某流 --out p.svg --color comfy      # 标题栏素色
cwf render 某流 --out p.png --no-widgets       # 不画控件条，只留骨架
cwf render 某流 --out p.png --no-notes         # 不画便签
cwf render 某流 --out p.png --no-legend        # 不画左上角图例
cwf render 某流 --out p.png --open             # 渲染完用系统默认程序打开
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--out` | **必填** | 输出路径；扩展名决定格式。**不写 `--out` 会报错**——这工具默认不落盘 |
| `--format` | 按扩展名 | `svg` / `png` |
| `--scale` | `1.0` | 整体缩放 |
| `--max-px` | PNG 4200 / SVG 不限 | 长边像素上限，超了自动等比缩小；`0` = 不限 |
| `--pad` | `48` | 四周留白 |
| `--theme` | `dark` | `dark` / `light` |
| `--color` | `function` | `function` 按功能分类上色 / `comfy` 素色 / `none` |
| `--font` | `1.0` | 字号缩放 |
| `--title` | 文件名 | 图例上的标题 |

## 画的是什么

| 元素 | 画法 |
|---|---|
| 节点 | 圆角框 + 标题栏（30 px）+ 端口圆点（左入右出）+ 控件条 |
| 标题栏 | 默认按**功能分类**配色；节点自带 `color` 时以工作流里的为准 |
| 副标题 | 只在标题被改过时出现（标题栏右侧灰字显示原始类型名） |
| 控件条 | `名字 值`；值超宽从**开头**截断（模型名的区分度在前面） |
| 连线 | 三次贝塞尔，按数据类型上色（MODEL 淡紫 / CLIP 黄 / LATENT 粉 / IMAGE 蓝 …） |
| 自定义类型 | 按类型名哈希取色，**同一个类型每次渲染同色** |
| 分区框 | 半透明圆角框 + 标题条 |
| 便签 | 贴纸样式，正文自动换行 |
| 静音 / 旁路 | 半透明色罩 + 「静音 MUTE」/「旁路 BYPASS」 |
| 图例 | 左上（其实是左下）列出本次出现的功能分类与节点数 |
| 右下角 | `N 节点 · M 连线 · W×H px` |

尺寸常量与 ComfyUI / LiteGraph 对齐（标题栏 30、端口行 20、圆角 8），
所以版式看起来就是前端那个样子。

---

## 两处**有意**不照抄前端

都是为了让**静态图**比前端截图更好用：

1. **标题栏按功能分类上色**，不是清一色深灰。
   一眼就能看出"哪段在加载模型、哪段在采样、哪段在出图"。
   要跟前端一样用 `--color comfy`。
2. **控件条显示 `名字: 值`**，不只是值。
   静态图没有悬停提示，只写个 `28` 谁都看不出那是步数。
   要纯前端观感用 `--no-widget-names`。

另外：**节点自己带的 `color`/`bgcolor` 永远优先**。你的工作流里 38% 的节点
是手动标过色的，那是你刻意的分区标记，渲染器不会覆盖它。

---

## 渲染器不做什么

* **不是 ComfyUI 前端截图** —— 没有下拉框、没有小地图、没有节点选中态、没有节点内部动画；
* **不执行任何 JS** —— 动态生成的端口（比如某些节点的可变输入）按工作流里存下来的样子画；
* **不替你排版** —— 图乱就是原图乱。先 `cwf beautify 某流 --out 排好的.json` 再 render；
* **不做精确文本度量** —— SVG 端拿不到真实字宽，中文按 1 em、拉丁按 0.55 em 估算，
  截断偶尔会差一两个字符。要绝对精确就用 PNG（那边有真实字体度量）。

---

## 大图怎么办

几千节点的图，PNG 缩到 4200 px 后字会很小。命令会主动提示：

```
⚠ 缩到 ×0.31 了，字会偏小。想要大字：
    · 出 SVG（矢量，放多大都清晰）：`--out out.svg`
    · 或者放开上限：`--max-px 0 --scale 1.5`
```

经验值：**节点数 > 200 就出 SVG**。

---

## 和 `layout` 的关系

```
cwf beautify 原始.json --out 排好的.json     # 先排版（分层、消重叠、语义分区）
cwf render  排好的.json --out preview.svg    # 再出图
```

`--validate` 出来的图不用管排版——渲染只读坐标，不改任何东西。
